01

Ingestion des Données

Collecte et structuration des données brutes depuis Kaggle.

Sources de Données

  • train.csv - 125M transactions (2013-2017)
  • stores.csv - 54 magasins (ville, type, cluster)
  • items.csv - 4,000+ produits (famille, périssable)
  • oil.csv - Prix du pétrole (impact économique Équateur)
  • holidays_events.csv - Calendrier des fêtes
  • transactions.csv - Volume quotidien par magasin

03

Feature Engineering

Création de variables explicatives pour capturer les signaux temporels.

Features Temporelles

  • Lags - Ventes J-16, J-21, J-28 (éviter fuite)
  • Rolling Mean/Std - Moyenne mobile 7 jours
  • Date Features - Jour semaine, mois, payday, fin d'année

Features Contextuelles

  • Prix pétrole lissé - Rolling mean 7j + lag 10j
  • Indicateurs fériés - National, régional, local, transfert
  • Target Encoding - Moyenne ventes par (store, item)
# Lags et Rolling Features
lf = lf.with_columns([
    pl.col("unit_sales").shift(16).over(["store_nbr", "item_nbr"]).alias("lag_16"),
    pl.col("unit_sales").rolling_mean(7).over(["store_nbr", "item_nbr"]).alias("rolling_mean_7"),
])
04

Modélisation

Entraînement LightGBM avec tracking MLflow et validation temporelle.

Configuration LightGBM

Objectiveregression
Learning Rate0.03
Num Leaves63
Max Depth8
RegularizationL1=0.1, L2=0.1
Early Stopping100 rounds

Validation Strategy

  • Fenêtre glissante - Train 7 semaines, Gap 7 jours, Valid 2 semaines
  • Métrique - NWRMSLE (Normalized Weighted RMSLE)
  • Poids - Périssables x1.25 (pénalité rupture)
